# autoRPG 확장 게임 시스템 설계안

작성일: 2026-09-01
기준 저장소: `g9inlife-blip/autoRPG`

## 개발 기준

이 문서는 `work/` 영역에서 진행하는 새 게임 개발의 기준 설계 문서다.

## 핵심 원칙

> 엔진은 규칙을 알고, 콘텐츠는 데이터가 결정한다.

- 게임 로직과 UI를 분리한다.
- HTML/CSS는 교체 가능하게 한다.
- 던전/퀘스트/스토리/이벤트는 데이터 중심으로 확장한다.
- Dungeon과 DungeonRun을 분리한다.
- Story와 Quest를 분리하고 Flag/Condition/Effect를 공통으로 사용한다.
- Seeded Random으로 전투를 재현할 수 있게 한다.
- 탐험 중 DungeonRun에서 캐릭터별 누적 DPS, 전투 통계, 획득 아이템/골드/경험치를 확인한다.
- 새 콘텐츠 추가에 엔진 코드 수정이 필요하지 않도록 한다.

## Character


## Battle

```text
BattleEngine
├─ TurnManager
├─ Initiative
├─ ActionResolver
├─ AttackResolver
├─ SkillResolver
├─ StatusResolver
├─ DamageCalculator
├─ DeathResolver
├─ EscapeResolver
├─ LootResolver
└─ BattleLog
```

전투 흐름:

```text
Battle Start → Enemy 생성 → Surprise → Round
→ PlayerAI / EnemyAI → ActionResolver
→ Attack / Skill / Item / Escape
→ Status / Effect → Death
→ Round 종료 → 결과 판정
```

## AI / Tactics

행동 후보를 생성하고 각각 점수를 계산한 뒤 최고 점수 행동을 선택한다.

```text
ActionScore =
  BaseValue
  + TacticalWeight
  + SituationModifier
  + TargetModifier
  + RandomVariance
```

`CharacterActionEngine`, `PlayerActionEngine`, `EnemyActionEngine`, `Tactics` 개념을 확장한다.

## Random

게임 엔진에서 직접 `Math.random()`을 사용하지 않는다.

```text
RandomProvider
└─ SeededRandom
```

동일 Seed + 동일 입력은 동일한 난수열과 결과를 만들어 회귀 테스트와 버그 재현에 사용한다.

## Dungeon / DungeonRun

```text
Dungeon = 콘텐츠 정의
DungeonRun = 실제 탐험 세션
```

Dungeon:

```text
Dungeon
├─ floors[]
│  ├─ blocks[]
│  │  ├─ encounters[]
│  │  ├─ events[]
│  │  └─ rewards[]
│  └─ boss
├─ difficulty
└─ rules
```

던전 ID는 문자열을 사용한다.

```text
dungeon.ancient_forest
dungeon.goblin_cave
dungeon.goblin_fortress
dungeon.ancient_ruins
```

DungeonRun:

```text
DungeonRun
├─ runId
├─ dungeonId
├─ startTime
├─ currentFloor
├─ currentBlock
├─ elapsedTime
├─ party[]
├─ battleStats
├─ obtainedItems[]
├─ obtainedGold
├─ obtainedExp
├─ defeatedEnemies
└─ events[]
```

현재 실행 중인 Run은 `GameState.activeDungeonRun`으로 관리한다.

## Story

스토리는 선형 목록이 아니라 그래프 기반으로 만든다.

```text
Start
 ↓
Forest Entrance
 ├─ 조사한다 → Hidden Path
 └─ 무시한다 → Main Path
                 ↓
                Boss
```

StoryNode 예:

```json
{
  "id": "forest_entrance",
  "type": "dialogue",
  "speaker": "hero",
  "text": "숲 안쪽에서 이상한 소리가 들린다.",
  "choices": [
    { "text": "조사한다", "next": "forest_hidden_path" },
    { "text": "무시한다", "next": "forest_main_path" }
  ]
}
```

## Story / Flag / Unlock

```text
Story Choice
 ↓
Flag 변경
 ↓
UnlockEngine
 ↓
새 퀘스트 / 던전 / 이벤트
```

예:

```text
Goblin Village
├─ 도와준다 → goblin_friend = true → Goblin Cave Unlock
└─ 공격한다 → goblin_enemy = true → Goblin Fortress Unlock
```

조건은 아이템 보유, Flag, 퀘스트 상태, 던전 층, 캐릭터 상태 등을 지원한다.

## Quest

```text
Story = 왜 하는가
Quest = 무엇을 해야 하는가
Dungeon = 어디서 하는가
```

Objective 타입:

```text
kill
collect
explore
reach_floor
talk
choose
obtain_item
defeat_boss
trigger_event
```

Quest Chain도 분기를 지원한다.

```text
Q001 → Q002 → Q003
                 ├─ Q004A → Q005A
                 └─ Q004B → Q005B
```

## Event / Condition / Effect

```text
Condition
 ↓
Rule Engine
 ↓
Event
 ↓
Effect
```

Condition:

- flag
- item 보유
- quest 상태
- dungeon/floor
- character 상태

Effect:

- flag 변경
- item/gold/exp 지급
- dungeon unlock
- quest 완료
- story 이동
- battle 시작
